# План обучения работе с GitHub и Codex

## Первый цикл

- Создать или изменить файл.
- Проверить изменения перед коммитом.
- Создать коммит с понятным сообщением.
- Отправить изменения в GitHub.

## Следующие упражнения

- Создать отдельную ветку.
- Изменить README.
- Открыть pull request.
- Провести проверку изменений перед слиянием.
